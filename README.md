One original fortune-cookie line for a software developer, for make.fun's “Fortune Cookie Wisdom for Developers” bounty:

> The bug you seek tomorrow hides in the code you are sure of today.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: the same line every run.
